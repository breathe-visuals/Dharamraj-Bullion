# Dharamraj Silver Arts - Live Bullion Rate Web Application

## Project Overview

Build and maintain a professional live bullion rate website called **Dharamraj Silver Arts**.

The website displays live Gold and Silver rates by consuming live market feeds from two different bullion providers.

Current deployment stack:

* Frontend: HTML, CSS, JavaScript
* Backend: Node.js + Express
* Real-time updates: Socket.IO
* Hosting: Render
* Source Control: GitHub

## Important Technical Discovery

Originally the website connected directly from browser to provider sockets.

This caused deployment problems on Render because browser-side Socket.IO loading and CORS issues were inconsistent.

Current architecture:

Browser
↓
Own Node.js Server
↓
Provider Socket Feeds

The server receives live feed updates and pushes them to connected website users through Socket.IO.

This architecture must be preserved.

Do NOT switch back to browser-direct connections.

---

## Live Update Requirement

Extremely important:

Rates must update instantly.

Requirements:

* No frontend polling
* No setInterval API polling
* No refresh buttons
* No manual reloads
* Use real-time push updates

Flow:

Provider Feed
↓
Node Server
↓
Socket.IO Push
↓
Browser

Updates should appear immediately when source data changes.
